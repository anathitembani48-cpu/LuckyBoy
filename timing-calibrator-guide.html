Step-by-Step Instructions

1 Download Your Audio File

First, you need a nursery rhyme audio file (MP3 format). See the "⬇️ Get Audio Files" tab for download links.

File should be:

  • ✅ MP3 format (.mp3)
  • ✅ Clear audio quality
  • ✅ Saved on your computer

2 Open the Timing Calibrator

Open timing-calibrator.html in your web browser:

  • Right-click the file → "Open with" → Choose your browser
  • OR drag the file into your browser window
  • OR double-click to open with default browser

3 Upload Your Audio

In the calibrator:

  • Click "📁 Upload Audio File"
  • Select your nursery rhyme MP3 file
  • Wait for it to load (you'll see the audio player)

4 Enter the Rhyme Name

In the "🎶 Rhyme Name" field, type:

  • Example: "Twinkle Twinkle Little Star"
  • This will be the display name in your app

5 Start Capturing Timings

This is the main part:

  • Press PLAY on the audio player
  • Listen to the audio
  • When the first lyric starts, type it in the text box
  • Click "⏱ Capture Timing" (or press ENTER)

Example:

Audio plays: "Twinkle, twinkle, little star..."

You type: Twinkle, twinkle, little star

You click: Capture Timing at 0.5 seconds

Result: { time: 0.5, text: 'Twinkle, twinkle, little star' }

6 Continue for All Lyrics

Repeat the process for each lyric line:

  • Listen for the next lyric
  • Type the lyric text
  • Click "Capture Timing"
  • Move to the next lyric

💡 Pro Tip: Pausing

You can PAUSE the audio between lyrics if you need time to think about what to type next!

7 Review Your Timings

Below the audio player, you'll see a list of all captured timings:

  • ✅ Each showing the time and lyric text
  • 🗑️ Delete button if you made a mistake
  • See the list update in real-time

8 Copy the Generated Code

At the bottom, you'll see the "📋 Generated Code" section:

  • Shows your code in a dark box
  • Click "📋 Copy to Clipboard"
  • Code is now ready to paste

9 Update Your Database

Open nursery-rhymes-data.js in your text editor:

  • Find the nurseryRhymes object
  • Paste your code inside (after the opening brace)
  • Add a comma if there's code after it
  • Save the file

10 Test It!

Open audio-controls.html in your browser:

  • You should see your new rhyme button
  • Click it to play the audio
  • Watch the lyrics appear at the bottom! 🎉

💡 Tips & Tricks

🎯 Capturing Accuracy

Pro Tip: Click "Capture Timing" at the VERY START of when the lyric begins, not in the middle.

✅ Good:

Audio: "Twinkle..." (click at first "T")

❌ Avoid:

Audio: "Twinkle..." (click at the "le" part)

⌨️ Keyboard Shortcut

Instead of clicking the button every time, just press ENTER after typing a lyric!

Faster Workflow:

  • Type lyric → Press ENTER
  • Type next lyric → Press ENTER
  • Much faster than clicking! ⚡

⏸️ Pause the Audio

You don't have to type everything in real-time!

  • Click PAUSE on the audio player
  • Type the lyric you just heard
  • Click Capture Timing
  • Press PLAY again
  • Listen for the next lyric

🗑️ Making Mistakes

If you mess up a timing:

  • Individual fix: Click the "Delete" button next to the wrong timing
  • Start over: Click "🗑 Clear All" to remove everything
  • Manual edit: After copying, edit the code directly in nursery-rhymes-data.js

⏱️ Time Format

The calibrator automatically formats time to 1 decimal place:

Examples:

  • 0.5 seconds = half a second
  • 2.3 seconds = two and three-tenths seconds
  • 15.0 seconds = exactly 15 seconds

This is perfect accuracy for most songs!

🎵 Lyric Length

When capturing lyrics, consider:

  • Short versions: Just the key phrase
  • Full versions: Complete sentence or line

Option 1 (Short - More timings needed):

{ time: 0, text: 'Twinkle' }

{ time: 0.5, text: 'twinkle' }

Option 2 (Full - Simpler, fewer timings):

{ time: 0, text: 'Twinkle, twinkle, little star' }

Recommendation: Use Option 2 for nursery rhymes (simpler!)

✏️ Manual Editing

You can edit the code after copying if needed:

  • Fix typos in lyric text
  • Adjust timing by 0.1 or 0.2 seconds
  • Reorder lyrics if captured out of order

⚠️ Important:

Make sure to keep the format correct:

{ time: NUMBER, text: 'TEXT' }

Include the comma between items (except the last one)

🔊 Audio Quality

For best results:

  • ✅ Use clear, easy-to-hear audio
  • ✅ MP3 format works best
  • ✅ At least 128 kbps bitrate
  • ❌ Avoid very distorted or muffled audio
