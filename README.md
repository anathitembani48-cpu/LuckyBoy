# KiddosLearn 🎓

An interactive educational platform designed for young children to learn numbers, spelling, and nursery rhymes in a fun and engaging way.

## 📚 Features

- **Learn Numbers** - Interactive lessons to help kids master counting and number recognition
- **Spelling Practice** - Word games and exercises to improve spelling skills
- **Nursery Rhymes** - Delightful collection of nursery rhymes with audio and visuals
- **User-Friendly Interface** - Colorful and intuitive design tailored for children
- **Interactive Learning** - Engaging activities that make learning fun

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/anathitembani48-cpu/LuckyBoy.git
   cd LuckyBoy
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

## 🌐 Deployment

This project is deployed on **Netlify**. To deploy your own version:

1. Connect your GitHub repository to Netlify
2. Configure build settings:
   - Build command: `npm run build`
   - Publish directory: `build` (or your project's output folder)
3. Deploy!

[Visit KiddosLearn](https://kiddoslearn.netlify.app) (replace with your actual Netlify URL)
